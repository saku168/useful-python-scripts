# Useful Python Scripts

A collection of beginner-friendly Python utilities. No third-party packages required.

## Scripts
- `word_counter.py` — count words, characters and lines.
- `json_pretty.py` — validate and format a JSON file.
- `random_picker.py` — choose an item from a comma-separated list.

Run a script with `python filename.py`. Requires Python 3.9+.
